# FloSports
2025 E1WA Championship page Cypress tests

# Clone the repo
git clone https://github.com/ReginaMorris/FloSports.git

# cd into the newly created repo directory
cd FloSports

# download necessary tools
You can download Node.js and npm from nodejs.org

# installation of tools
npm install

# run cypress
npx cypress open
npx cypress run

# running tests
npx cypress run --spec "cypress/e2e/**/EIWAChampionship.cy.js"
